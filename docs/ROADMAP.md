# Roadmap

## Milestone 1 — Foundation
- [x] Kotlin multi-module Gradle structure
- [x] Compose application shell
- [x] Shared device and transport contracts
- [x] Android TV mDNS discovery starter
- [x] GitHub Actions debug-build workflow
- [ ] Verify CI build and resolve build issues

## Milestone 2 — Android TV Remote v2
- [ ] Device discovery lifecycle and multicast handling
- [ ] Certificate/key identity using Android Keystore
- [ ] Secure pairing and challenge verification
- [ ] Protobuf message framing and configuration handshake
- [ ] Key press/release events and reconnect state machine

## Milestone 3 — Standalone remote UX
- [ ] Discovered-device list and manual IP entry
- [ ] Pairing PIN screen
- [ ] D-pad, back, home, volume, and app shortcuts
- [ ] Text input and connection status

## Milestone 4 — Compatibility
- [ ] Legacy Android TV Remote v1 (Polo)
- [ ] LG webOS
- [ ] Roku
- [ ] Bluetooth HID
- [ ] Infrared

## Milestone 5 — Reuse
- [ ] Stable public API and documentation
- [ ] Publish reusable Android library
- [ ] Integrate remote engine into RetroTV
